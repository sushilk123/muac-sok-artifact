# SoK: Coordination Among Mutually Untrusting, Independently Developed AI Agents in Cloud Data Ecosystems

Artifact for the paper by **Sushil Khairnar** (Virginia Tech).

The paper systematizes research on *Mutually Untrusting Ad Hoc Coordination* (MUAC). In this setting, AI agents built by different vendors and run by different organizations must discover one another's capabilities, negotiate, delegate, and resolve conflicts. They have no prior joint training and do not fully trust one another. The paper:

- codes 85 works against eight requirements, and
- reports a 540-episode cross-vendor pilot study of data-access negotiation.

📄 **Paper:** [`paper/paper_ieee.pdf`](paper/paper_ieee.pdf)

## Repository layout

| Path | Contents |
|---|---|
| `paper/` | IEEE-format PDF, Markdown and Word versions, merged bibliography |
| `paper/latex/` | IEEEtran LaTeX source (`main.tex`, `refs_ieee.bib`, `TUptm.fd`). Compile with **XeLaTeX** or Tectonic. |
| `draft/` | Markdown source sections from which the paper is assembled |
| `coding/` | Systematization data. `coding_part{1,2,3}.md` holds the per-work codes with justifications, `master.json` / `master_table.md` the merged coding of all 85 works, `coverage_by_community.md` the aggregate coverage, and `refs_*.bib` the per-batch bibliographies. |
| `notes/` | Full-text reading notes on the four closest works, and the citation-verification log |
| `pilot/` | Pilot study. `pilot.py` is the experiment, `analyze.py` the analysis, `results.jsonl` contains all 540 episodes with full transcripts, and `results_summary.md` the aggregated tables. |
| `pilot/archive/` | The initial run, superseded and kept for transparency (see below) |
| `scripts/` | `build_table.py` (coding statistics), `build_paper.py` (assembles `paper/paper.md`), and `build_ieee.py` (generates the IEEE LaTeX) |

## Reproducing

```bash
pip install -r requirements.txt

# Coding statistics and tables
python3 scripts/build_table.py

# Pilot analysis (no API access needed)
python3 pilot/analyze.py pilot/results.jsonl

# Rebuild the paper
python3 scripts/build_paper.py
python3 scripts/build_ieee.py
cd paper/latex && tectonic main.tex   # or: xelatex + bibtex
```

**Re-running the pilot** requires Amazon Bedrock access to `us.anthropic.claude-haiku-4-5-20251001-v1:0`, `openai.gpt-oss-120b-1:0`, and `us.meta.llama3-3-70b-instruct-v1:0` in `us-east-1`. Credentials come from the standard AWS credential chain; none are stored in this repository.

```bash
python3 pilot/pilot.py --seeds 10 --workers 16 --out results_rerun.jsonl
```

The script stops automatically at a configurable budget cap (`BUDGET_USD`, default US$25). The full run cost about US$5, estimated from per-token list prices.

## Note on the archived run

The first pilot run detected free-form agreement with a keyword match, which incidental words such as "ideal" falsely triggered. Those 180 free-form episodes were discarded and re-run with explicit `DEAL:` / `WALK_AWAY` markers; the structured and gated episodes were unaffected. The final dataset, `pilot/results.jsonl`, combines the 360 unaffected structured and gated episodes with the 180 re-run free-form episodes. The original run (`pilot/archive/results_v1_all.jsonl`) and its code (`pilot/archive/pilot_v1.py`) are kept for transparency. They should not be used for analysis.

## Coding caveats

Coding was performed in a single pass by one coder, without inter-rater agreement. Of the 85 works, 12 were coded from full text and 73 from abstracts or official pages. The repository is released so that others can contest and update individual codes; corrections are welcome via issues or pull requests.
